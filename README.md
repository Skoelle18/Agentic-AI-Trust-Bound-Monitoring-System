# ATBMS — Agentic AI Trust-Boundary Monitoring System

Production-grade security platform that intercepts, audits, and enforces trust policies across AI agent workloads and MCP tool-call pipelines.

## Quick start (Docker)

From the repo workspace root:

```bash
cd atbms
./setup.sh
docker compose up --build
```

Open:
- `http://localhost:3000` (React dashboard)
- `http://localhost:8080` (Nginx gateway, optional)

## Demo flow

1. Open **Live Feed**
2. Click **Run Demo**
3. Watch real-time events stream in via SSE (`proxy /api/stream`)
4. Navigate across pages:
   - **Agent Registry**: live agents from registry, blast radius graph
   - **Policies**: edit Rego and hot deploy; see effects in proxy decisions
   - **Anomaly**: alerts generated by polling audit events
   - **Audit Log**: verify hash chain integrity

## Services / Ports

- Proxy (Layer 2): `http://localhost:8000`
- Registry (Layer 1): `http://localhost:8001`
- Policy (Layer 3): `http://localhost:8002`
- Anomaly (Layer 4): `http://localhost:8003`
- Audit (Layer 5): `http://localhost:8004`
- OPA: `http://localhost:8181`

## Config

- `config/allowlist.yaml`: tool allowlist and upstream system mapping
- `config/policies/main.rego`: OPA policy
- `config/keys/*`: audit ECDSA signing keypair (generated by `setup.sh` or audit on startup)
